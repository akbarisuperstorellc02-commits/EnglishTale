# EnglishTale — Programmatic Visual Assets

These original illustrations are authored as editable, resolution-independent SVG files using code (no external image-generation service).

## Use
SVG files can be opened in modern browsers, imported into many video editors, or rasterized to PNG at any target resolution. The artwork is intentionally vector-based so it can be edited and scaled without pixelation.

## Important production note
These are clean 2D vector scene plates and character illustrations, not finished animation or final video footage. Future commits can add alternate poses, mouth shapes, layered character parts, and shot-specific compositions.
