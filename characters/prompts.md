# Character Reference Prompts

Generate each character separately on a plain warm-cream background. Save the best matching output as the approved reference image. Do not rely on prompt text alone for continuity. The character bible is authoritative.

## Leo — master prompt

Create an original, polished 3D animated educational-story character named Leo. He is a friendly fictional 19-year-old young adult traveler with soft slightly tousled brown hair, expressive warm brown eyes, a **clearly blue hoodie (not red)**, dark navy jeans, and clean white sneakers. Full-body front view, relaxed neutral standing pose, friendly slightly nervous smile, appealing but believable proportions, expressive face, soft studio lighting, detailed fabric, premium family-friendly 3D animation, plain warm cream background. Character model sheet quality. No text, no logos, no watermark, no props.

## Ollie — master prompt

Create an original, adorable **small owl (bird, not a dog)** mascot named Ollie for an English-learning animation brand. Warm brown feathers, cream-colored face and chest, large expressive amber eyes, round simple glasses, a navy-blue scarf with a tiny golden accent. Full-body front view, standing upright on two small feet, cheerful welcoming expression, polished original 3D animation, soft studio lighting, plain warm cream background. Keep the design simple and recognizable at small sizes. No dog features, no fur, no muzzle, no floppy ears, no text, no logos, no watermark.

## Airport agent — master prompt

Create an original friendly adult airport check-in employee for a family-friendly 3D animated educational story. Professional navy and light-blue uniform with no airline branding, neat appearance, warm polite expression, full-body front view, plain warm cream background, polished cinematic 3D animation. No text, no logos, no watermark.

## Expression sheets

For each approved character, generate a 3×2 expression sheet with:
- neutral listening
- happy smile
- surprised
- worried / confused
- speaking
- thoughtful

Keep the exact approved clothing and physical design. Do not add labels or text.

## Acceptance gate

Reject any result where Leo's hoodie is red or another color, Emma's sweater is not pink, or Ollie is not unmistakably an owl. Reject inconsistent face shapes, extra limbs, malformed hands, unreadable accidental text, logos, watermarks, and mixed character identities. Only approved reference images may be used as inputs for episode scenes.
