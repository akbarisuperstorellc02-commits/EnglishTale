# Character Bible

The following are original, fictional characters. Keep their appearance stable across all episodes. Use approved reference images as image references whenever the generation tool supports them.

## Leo — learner / main character
- Fictional young adult, approximately 19.
- Soft, slightly tousled brown hair; expressive brown eyes.
- Blue hoodie, dark blue jeans, white sneakers.
- Curious, kind, sometimes nervous in unfamiliar situations.
- Learns language by trying, making small mistakes, and improving.
- Default body language: open posture, expressive hands, readable facial expressions.

## Emma — supportive friend
- Fictional young adult, approximately 19.
- Shoulder-length brown hair; expressive brown eyes.
- Pink sweater, dark jeans, white sneakers.
- Calm, encouraging, practical, friendly.
- Helps Leo without sounding like a lecturer.

## Ollie — lesson guide
- Original small owl mascot; warm brown feathers, large expressive eyes, round glasses, navy-blue scarf with a small golden accent.
- Cheerful, concise, encouraging.
- Appears mainly in lesson recap and quiz sections.
- Do not make Ollie resemble an existing branded character.

## Airport agent
- Fictional adult airport employee.
- Professional neutral uniform in navy and light blue, no real airline logos.
- Polite, calm, helpful.

## Continuity rules
1. Never change clothing, hair, eye color, age impression, or body proportions between shots in the same episode.
2. Do not add logos, brand marks, readable signage, or text unless manually added in post-production.
3. Use the same seed/reference image when available.
4. Generate a character reference sheet before scene artwork.
5. For two-character shots, provide both reference images if supported.
6. Inspect hands, faces, clothing, and background artifacts before accepting a generation.
